How US computer science departments handle generative AI

We read the official AI language of 42 US computer science departments, their universities, and their intro and software engineering courses, then coded it against a fixed codebook. Every code cites a quoted source. The project was built by an AI agent (Claude Code) working from specs, tests and human reviews.

About this project

Built for a generative AI software development course. Adi supervised through phase specs, acceptance tests and reviews; Claude Code wrote the code, collected the sources and coded the policies. Every prompt and response was logged by hooks. Source code, data and logs: github.com/AdityaPawarr7/GenAiP2.
