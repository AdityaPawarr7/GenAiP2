## intro_course
course: CS 5 Introduction to Computer Science, Fall 2026
url: https://www.cs.hmc.edu/twiki/bin/view/CS5/CourseSyllabus
source_date: 2026 "CS 5 Course Syllabus, Fall 2026"
> AI is an tool well-suited to computational exploration; it is welcome, though not required. Note that, following professional practice, each student is fully accountable for AI-generated content that they make part of a deliverable. (Blaming AI is tempting, but not acceptable in cs5.)

> For code, you do not have to cite the use of LLMs: they are a standard tool for supporting people in the creation of source code and software systems.

> It is possible to thrive in CS5 without AI at all (many generations of students have done so!), and you are welcome not to use it. You are also welcome to use it under constraints of your choosing

course: CS 70 Data Structures & Program Development (Melissa O'Neill), Fall 2026
url: https://www.cs.hmc.edu/cs70/policies/syllabus/
source_date: 2026 "for Fall 2026."
> you may not use any kind of AI assistant (such as GitHub Co-Pilot) to write code for this class (or even suggest code you can write).

> In all respects, using AI (such as ChatGPT or GitHub Copilot) is equivalent to turning to a friend who has already taken the class and asking them for help—the same rules apply.

> Using LLMs to generate code for assignments or projects is strictly prohibited. This prohibition includes using coding assistants like GitHub Copilot to “autocomplete” code.

> You may use LLMs to help further explore concepts from lessons or to get alternative explanations of course material.
