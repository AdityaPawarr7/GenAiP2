## university_guidance
url: https://ctl.duke.edu/ai-and-teaching-at-duke-2/artificial-intelligence-policies-in-syllabi-guidelines-and-considerations/
source_date: 2026 "Last updated: August 9, 2026"
> Under the Duke Community Standard, the unauthorized use of generative AI to complete assignments, exams, and other academic assignments is considered academic dishonesty. The university’s statement sets a base level policy, however, it does not explain what unauthorized means for your course.

> All instructors should update their syllabi to include clear guidance on the use of generative AI in their courses. We encourage faculty to thoughtfully determine their stance, recognizing that in a rapidly evolving AI landscape, standardized, one-size-fits-all policies are neither sustainable nor reflective of the diversity of teaching approaches.

> We do not recommend AI detection software as a part of your AI policy because of false positive rates, biased detections, and software shortcomings

## intro_course
course: CompSci 101 Introduction to Computer Science, Fall 2026
url: https://courses.cs.duke.edu/fall26/compsci101/info.php
source_date: 2026 "CompSci 101, Fall 2026, Syllabus"
> You cannot use any AI, such as LLMs to solve problems and write code for you. This is a beginning programming course, so you need to do the problem solving in order to learn how to solve problems and write code.

> You can use AI (LLMs) to answer information questions such as "What is X?", "What is the format of an X statement in Python?", "Give me an example of X for a beginner?"

course: CompSci 201 Data Structures and Algorithms, Fall 2026
url: https://coursework.cs.duke.edu/201fall26/resources-201/-/raw/main/course%20documents/syllabus.md
source_date: 2026 "Syllabus for Compsci 201, Fall 2026"
> We encourage you to use LLMs as part of understanding material in the course, but not to do the work for you. For example, you can ask an LLM to explain what an instance variable is, or why ArrayList.add is amortized constant time. However, you should not ask an LLM to write code specific to an assignment -- instead ask for something more generic that you can use to answer questions you have. If you do use an LLM as you work on an assignment, we ask that you indicate that in the README

> For in-class exams and for APT quizzes, **you may not use any AI-assistance.

> We ask you to **either not install, or to disable CoPilot** when working on APTs and assignments.
